# 天语言 `/` 声明语法评估稿

> 状态：决策参考文档（非规范）。目的：把 v0.1 定稿时"斜杠声明前缀"的取舍摆到桌面上，
> 在语言被更多人（和更多 AI）使用之前，评估是否值得修订，以及若修订选哪个方案。
> 规范 2.7 是现行标准，本文档不改变任何现行行为。

## 1. 现状回顾

天语言用 `/a` 声明只读变量、`//b` 声明可变变量，并用 `w/ i/ f/ e/ r/` 作流程标记。
为此规范 2.7（v0.1.1）建立了一套斜杠判定规则：

1. 表达式内（前一 Token 是操作数结尾）→ `/` 恒为除号；
2. 语句边界且后接标识符 → 声明前缀；
3. 其余 → 除号。

规范自认的两处破绽：
- 表达式内对名为 `e`/`r` 的变量做除法被标记字规则拦截：`x=e/y` 非法，须写 `x=(e)/y`（2.2）；
- `8//b` 形态无法书写（2.7 已知取舍）。

## 2. 实际伤害评估（截至 v3.5）

| 伤害 | 严重度 | 说明 |
|------|--------|------|
| 变量名被标记字污染 | 中 | `e` `r` `w` `i` `f` 单独作变量名时，含它们的除法表达式要加括号 |
| 除法可读性 | 低 | `cnt/a` 工作正常（v0.1.1 已修），只有罕见组合出问题 |
| 未来扩展冲突 | **高** | 函数要成为一等公民（把 `f` 传值）、新增控制流（`for`/`match`）时，单字母+`/` 的命名空间会继续挤压 |
| AI 生成错误率 | 中 | 实测中 AI 会偶发写出被误判的表达式；`--diagnose-json` 能兜住但多一轮修复循环 |

结论：**当下可用，未来承压**。核心矛盾不是现在的除法，而是"标记字命名空间"随语言成长不断变窄。

## 3. 候选方案

### 方案 A：维持现状（符号极简派）
- 优点：已定稿、已实现、测试齐全；源码最短；美学统一（"斜杠 = 结构标记"是语言个性）。
- 缺点：命名空间债持续累积；每个新关键字都要发明 `x/` 记号。
- 适合：若天语言的定位是"个人语言 / 教学原型"，成本可接受。

### 方案 B：关键字化（`let` / `var`，流程用 `while`/`if`/`fn`）【推荐】
- 优点：零歧义（关键字不可作标识符，判定是平凡规则）；AI 生成零失误；
  与 C/Rust/Python 的先例一致，学习成本最低；命名空间永久解放。
- 缺点：源码变长（`//cnt=1` → `let mut cnt=1`）；推翻 v0.1 承诺"定稿不改"。
- 迁移成本评估：现有程序都是小样例（5 个验收程序 + 32 个测试用例），
  一次性机械替换即可，编译器改 lexer/parser 各几十行。**越晚改成本越高**——
  等真实用户出现后这就不再是可行选项。

### 方案 C：折中——声明后缀化（`a:=20` / `a::=20`）
- 优点：保留符号风格；`:=` 在赋值语境出现，天然无歧义（表达式里 `a:=b` 不合法，可机械判定）；
  流程标记可改为 `while:` 等。
- 缺点：`:=` 对初学者不如 `let` 直白；仍需处理 `w/` 等流程标记的替换，改动量与 B 相当。

### 方案 D：声明前缀仅在行首合法（微修订）
- 优点：改动最小；`/ a`（空格）已是除号，把"紧贴 + 行首"作为声明的唯一合法位置，
  可消除 2.7 的大部分上下文判定。
- 缺点：治标不治本——标记字命名空间问题原样保留；`x=e/y` 仍非法。

## 4. 决策建议

**若天语言要走向公开使用：选 B（关键字化），且在 v4.0 之前完成。**
理由排序：
1. 天语言的差异化竞争力在语义锚点、差分诊断、天权这些"AI 原生"机制上，
   不在"斜杠标记"这种表层美学上；为表层美学背命名空间债不划算。
2. 语法糖可以后加，语法错误不能后删——B 之后再想加回 `/` 简写是纯增量，反向则近乎不可能。
3. AI 是第一用户：关键字是 AI 训练分布内最强的先验，生成的错误率实质下降。

**若维持个人原型定位：选 A，但立即冻结**——不再新增任何 `x/` 标记字，
新控制流一律走函数式方案（如 `cond(a, b, c)` 三元函数）。

## 5. 若选 B 的迁移清单（预估工作量）

1. lexer：删除 ReadOnlyDecl/MutableDecl/While/If/Else/Fn/Return 标记字，新增关键字
   `let` `var` `while` `if` `else` `fn` `return`（半天）。
2. parser：前缀改为关键字消费（半天）。
3. 规范 2.2/2.7/3/5 全章重写，2.7 直接删除（半天）。
4. 测试用例机械替换 + 新增"关键字不可作标识符"用例（1 小时）。
5. 提供一次性迁移脚本 `tc fix --slash-to-let`（1 天，可选但体面）。
